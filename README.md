# Repository standards

Shared contribution guidelines and issue/pull request templates for Muath Alsulami's public repositories. Individual repositories may provide more specific instructions.

Portfolio projects use lowercase kebab-case names, concise descriptions and accurate topics. Public project documentation covers the problem, implemented features, setup, verification, limitations and actual contribution. Pin only strong, runnable case studies.

For a new project, start with [portfolio-project-template](https://github.com/muathmalsulami/portfolio-project-template). This configuration repository is not a portfolio project.
