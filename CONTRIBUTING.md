# Contributing

Read the project's README and current limitations before proposing a change. Open an issue describing the problem and expected outcome for substantial changes.

Keep pull requests focused, explain the behavior change and record checks actually performed. Credit external code, data and models and preserve their license notices. Never include credentials, private records or proprietary material in code, logs or screenshots.

Do not report a security vulnerability in a public issue. Use the repository's private vulnerability reporting channel when enabled; otherwise contact the maintainer privately through the contact listed in the profile.
