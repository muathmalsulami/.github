# Security reporting

Please do not disclose vulnerabilities, credentials or private user data in public issues or pull requests.

Use GitHub's private vulnerability reporting option when it is enabled for the affected repository. Otherwise, contact **muath.m.alsulami@gmail.com** with the repository name, affected version/commit, a short description and non-sensitive reproduction steps. Do not email credentials, personal records or exploit output containing private data.
